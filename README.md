# 중세국어 키보드 (MidageKeyboard)

ㅿ·ㆁ·ㆆ·ㆍ·ㅸ와 방점까지 입력할 수 있는 안드로이드용 옛한글 키보드입니다. 삼성 기본 키보드와 비슷한 모양입니다.

## 설치
1. 오른쪽 **Releases**에서 가장 최근 것을 눌러 `MidageKeyboard.apk`를 내려받습니다.
2. 설치할 때 '출처를 알 수 없는 앱' 설치를 허용합니다.
3. 앱을 열고 **키보드 켜기 → 키보드 고르기**를 누릅니다.

## 쓰는 법
- 윗줄: ㆍ ㅿ ㆁ ㆆ ㅸ ㆎ, 방점(거성 〮 / 상성 〯)
- 길게 누르기: ㅅ→ㅿ, ㅇ→ㆁ, ㅎ→ㆆ, ㅏ→ㆍ, ㅂ→ㅸ, ㅁ→ㅱ, ㅍ→ㆄ, ㅛ→ㆇ, ㅠ→ㆊ …
- 이어 치기: ㅂ+ㅇ=ㅸ, ㅅ+ㄱ=ㅺ, ㅂ+ㅅ+ㄱ=ㅴ, ㆍ+ㅣ=ㆎ
- '옛' 글쇠: 드문 옛글자 모음 / '한/영': 영어 자판 / '!#1': 숫자·기호

코드를 main에 올리면 GitHub Actions가 APK를 자동으로 빌드해 Releases에 올립니다.
